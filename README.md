# WebView2 桌面应用
基于 .NET 8 WinForms + WebView2 开发的轻量级桌面浏览器应用，支持自定义网址和窗口标题，一键配置，开箱即用。

## ✨ 功能特性
- 🚀 **极速启动**：基于原生 WinForms 和 WebView2 内核，启动速度快，内存占用低
- ⚙️ **灵活配置**：支持自定义默认网址和窗口标题，配置实时生效
- ⌨️ **全局快捷键**：按 `Ctrl+,` 随时唤起配置窗口，无需退出应用
- 📦 **标准安装包**：生成 MSI 安装包，自动创建桌面和开始菜单快捷方式
- 🔧 **自动依赖检测**：安装时自动检测缺失的 .NET 8 和 WebView2 运行时，引导在线下载
- 🌐 **局域网支持**：完美支持内网 HTTP 地址访问
- 🛡️ **绿色安全**：无任何第三方依赖，纯原生代码开发

## 🖥️ 运行环境要求
- 操作系统：Windows 10 1809 及以上版本 / Windows 11
- 运行时依赖（安装包会自动引导下载）：
  - [.NET 8 桌面运行时](https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0)
  - [Microsoft Edge WebView2 运行时](https://developer.microsoft.com/zh-cn/microsoft-edge/webview2/)

## 📥 安装说明
1. 从 GitHub Actions 下载最新的 `WebView2应用完整包`
2. 解压后得到两个文件/文件夹：
   - `WebView2桌面应用.msi`：一键安装包（推荐）
   - `App` 文件夹：绿色免安装版
3. 双击运行 `WebView2桌面应用.msi`，按照向导完成安装
4. 安装完成后，桌面和开始菜单会自动创建快捷方式

## 📖 使用指南
### 基本使用
1. 双击桌面快捷方式启动应用
2. 应用会自动加载配置的默认网址
3. 可以像使用普通浏览器一样操作网页

### 修改配置
1. 按全局快捷键 `Ctrl+,` 唤起配置窗口
2. 在配置窗口中修改：
   - **程序标题**：窗口左上角显示的标题
   - **默认网址**：应用启动时自动加载的网页地址
3. 点击「保存配置」按钮，修改立即生效
4. 按 `ESC` 键可以快速关闭配置窗口

### 退出应用
- 点击窗口右上角的关闭按钮
- 或右键点击任务栏图标，选择「关闭窗口」
